# Event-Expense-Manager-Novazul

Sistema de controle de gastos em eventos corporativos, desenvolvido com Google Apps Script.

## 🚀 Objetivo

Automatizar o registro, aprovação e pagamento de gastos realizados por funcionários em eventos.

## 🧠 Funcionalidades

- Registro de gastos via Google Forms
- Armazenamento em Google Sheets
- Processamento via Apps Script
- Interface para financeiro
- Envio automático de emails
- Geração de relatórios
